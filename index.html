ขั้นตอนที่ 1: เตรียมไฟล์

คัดลอกโค้ดไฟล์นี้ทั้งหมดแล้วบันทึกในชื่อ index.html ไว้บนคอมพิวเตอร์

ขั้นตอนที่ 2: สร้าง Repository บน GitHub

1. สมัครหรือเข้าสู่ระบบ GitHub.com

2. คลิกปุ่ม New Repository ตั้งชื่อ เช่น my-portfolio แล้วเลือกเป็น Public จากนั้นกด Create Repository

ขั้นตอนที่ 3: อัปโหลดไฟล์ index.html

ในหน้า Repository คลิกปุ่ม uploading an existing file ลากไฟล์ index.html ลงไป แล้วกด Commit changes

ขั้นตอนที่ 4: เปิดใช้งาน GitHub Pages

1. เข้าไปที่เมนู Settings > Pages

2. ในส่วน Build and deployment ให้เปลี่ยน Source เป็น Deploy from a branch แล้วเลือก Branch เป็น main (หรือ master) แล้วกด Save

3. รอระบบดำเนินการประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น https://yourusername.github.io/my-portfolio สามารถนำไปแนบใน Portfolio ยื่นสมัครงานหรือการศึกษาได้เลยครับ!
